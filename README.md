# Mogify Studio — Website

Official website of **Mogify Studio**, a creative and digital product studio in Karachi, Pakistan, founded by Muhammad Moiz Ali.

Live: https://mogifystudio.sites.tab.bot/

## Built with
- HTML5, CSS3, vanilla JavaScript (hand-coded, no site builder)
- [GSAP](https://gsap.com/) with ScrollTrigger and SplitText for scroll and text animations
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling
- Fonts: Manrope, Inter, Fraunces, Space Grotesk (self-hosted)
- SEO: meta tags, Open Graph, Schema.org JSON-LD, sitemap.xml, robots.txt

## Structure
```
index.html        main page
styles.css        styles
script.js         interactions and animations
work/             portfolio case pages
assets/           images, brand files, fonts, video, js libraries
```

## Run locally
Open `index.html` in a browser, or serve the folder:
```
npx serve .
```
